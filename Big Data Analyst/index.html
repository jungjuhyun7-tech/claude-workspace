# 📊 빅분기 오답 대시보드

> [!warning] 요구 플러그인
> 아래 쿼리는 커뮤니티 플러그인 **Dataview** 설치·활성화가 필요합니다.
> 설정 → 커뮤니티 플러그인 → 검색 "Dataview" → 설치 → 활성화.
> Dataview를 쓰지 않는다면 맨 아래 "수동 인덱스" 방식을 사용하십시오.

## 1. 원인별 오답 분포 (내 약점의 지도)
```dataview
TABLE length(rows) AS "건수"
FROM ""
WHERE 유형 = "오답노트"
GROUP BY 원인
SORT length(rows) DESC
```
**해석 규칙:** `개념누락`이 1위면 교재 회독 부족 → 해당 과목 교재 재독. `함정`이 1위면 문제 풀이량 부족 → 기출 회차 추가. `계산실수`가 1위면 드릴 부족 → bigdata-calc-drill.html 매일 10문제.

## 2. 과목별 오답 분포 (과락 위험 탐지)
```dataview
TABLE length(rows) AS "건수"
FROM ""
WHERE 유형 = "오답노트"
GROUP BY 과목
SORT length(rows) DESC
```
특정 과목이 전체 오답의 40%를 넘으면 과락 경보 — 그 과목의 "오늘 반드시 외울 것" 12항목부터 재점검.

## 3. 미청산 오답 (복습 대기열)
```dataview
TABLE 회차, 문항, 원인, 복습횟수
FROM ""
WHERE 유형 = "오답노트" AND 청산 = false
SORT 복습횟수 ASC, 날짜 ASC
```

## 4. 🟡 함정 태그만 모아보기 (시험 2주 전 전용)
```dataview
LIST
FROM #함정
WHERE 유형 = "오답노트"
SORT 날짜 DESC
```

## 5. 청산 완료율
```dataview
TABLE length(rows) AS "건수"
FROM ""
WHERE 유형 = "오답노트"
GROUP BY 청산
```

# 오답노트 시스템 사용법 (5분 세팅)

## 1. 세팅
1. Obsidian 보관함(Vault)에 폴더 `빅분기/오답노트/` 생성.
2. `오답노트-템플릿.md`를 템플릿 폴더(설정 → 코어 플러그인 → 템플릿에서 지정한 폴더)에 넣는다.
3. `오답노트-대시보드.md`를 `빅분기/`에 넣는다. Dataview 플러그인 설치(대시보드 파일 상단 안내 참조).

## 2. 기록 워크플로 (오답 1건당 90초 목표)
1. 기출을 풀고 채점한다.
2. 틀린 문항마다 새 노트 생성 → 템플릿 삽입 → 파일명 규칙: `10회-42-혼동행렬` (회차-문항-개념).
3. **frontmatter 3필드만 필수**: `회차`, `과목`, `원인`(개념누락/함정/계산실수 중 택1).
4. 본문에서 해당 원인 태그 줄만 남기고, "한 줄 규칙"을 반드시 작성 — 이 한 줄이 노트의 존재 이유다. 규칙을 못 쓰겠으면 아직 왜 틀렸는지 모르는 것이므로 교재 해당 섹션으로 돌아간다.

## 3. 복습 워크플로
- 복습 주기: 오답 후 1일 → 3일 → 7일 (노트 하단 체크박스).
- 3차 복습에서 막힘 없이 풀리면 frontmatter `청산: true` + `복습횟수: 3`.
- **시험 D-14부터**: 대시보드 쿼리 4번(#함정만 모아보기)으로 함정 노트만 일괄 복습. 함정은 지식이 아니라 패턴이라 몰아 보는 것이 효율적이다.

## 4. 원인 태그 판정 기준 (애매할 때)
| 상황 | 태그 |
|---|---|
| 보기 4개 중 2개까지 좁혔는데 틀림 | #함정 |
| 문제를 읽고 무엇을 묻는지 몰랐음 | #개념누락 |
| 식은 세웠는데 답이 다름 | #계산실수 |
| 시간 부족으로 찍음 | #계산실수 (풀이 속도 문제 → 드릴) |

## 5. 다른 도구와의 연결
- `#계산실수` 누적 유형 → **bigdata-calc-drill.html**의 해당 유형 버튼으로 10문제 연속 정답까지 반복.
- `#개념누락` 누적 과목 → 통합 허브(bigdata-master-hub.html)에서 해당 과목 교재의 그 섹션만 재독.
- `#함정` 한 줄 규칙 중 반복되는 것 → Anki에 직접 카드로 추가(bigdata-anki-all 덱에 노트 추가).
